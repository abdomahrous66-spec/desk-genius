# Roadmap

- [ ] Make English the default interface across every route and add a persistent Arabic/English switch.
- [ ] Redesign user access around three permission groups: View, Create, and Admin.
- [ ] Allow separate company/sector/department scopes and JD/TP or JD/TN choices per permission group.
- [ ] Restrict delegated admins to viewing, granting, creating, and deleting only inside their own assigned scope.
- [ ] Enforce the same authorization rules in database policies and frontend controls.
- [ ] Validate role assignment, cross-company isolation, core routes, and production build.
